With a clean interface, responsive controls and an easy-to-configure architecture, Vaani Music brings a simple and enjoyable music experience to your Telegram community.

✦ 𝐂𝐨𝐦𝐦𝐚𝐧𝐝𝐬

Command| Description
"/start"| Start the bot
"/help"| Show help menu
"/play"| Play a song
"/pause"| Pause playback
"/resume"| Resume playback
"/skip"| Skip current song
"/stop"| Stop playback
"/queue"| View current queue
"/playlist"| Manage playlists
"/ping"| Check bot response

«⚠️ Commands may vary depending on your configured handlers and bot version.»

✦ 𝐐𝐮𝐢𝐜𝐤 𝐒𝐞𝐭𝐮𝐩

① Clone Repository

git clone YOUR_REPOSITORY_URL
cd VaaniMusic

② Install Dependencies

pip install -r requirements.txt

③ Configure Environment

Create a ".env" file:

BOT_TOKEN=YOUR_BOT_TOKEN
API_ID=YOUR_API_ID
API_HASH=YOUR_API_HASH

MONGO_DB_URI=YOUR_MONGODB_URI

OWNER_ID=YOUR_TELEGRAM_ID

④ Start Bot

python bot.py
