🚀 𝐈𝐧𝐬𝐭𝐚𝐥𝐥𝐚𝐭𝐢𝐨𝐧

① Clone

git clone YOUR_REPOSITORY_URL
cd VaaniMusicBot

② Install Dependencies

pip install -r requirements.txt

③ Configure

Create your ".env" file and add the required credentials.

④ Start

python bot.py
